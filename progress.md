## 20 October 2026 — WP-S2 streamed answers (branch `feat/ask-261020-stage1`, uncommitted, local only)

**Design (as implemented):** streaming is opt-in. A browser that can read a stream sends `Accept: text/event-stream, application/json`; the route returns the ordinary JSON answer whenever it does not, or when no text was produced (validation error, allowance, reused cached answer), so status codes are unchanged. Once text starts, the response is server-sent events: `delta` events (display text) then exactly one `done` (the complete validated answer, links, cached flag) or `error` (the public error). The browser keeps only the final event and replaces the streamed text with it. Display text is withheld until the provider reports a completed file search, provider citation markers are removed (including across chunk boundaries), and it is capped at 20,000 bytes. The answer itself is still taken only from the provider's `response.completed` object and passes every existing check (empty, length, retrieval completed, fingerprints, reservation commit) before it is cached, recorded or offered to the Premium seams. A failure after text was shown ends in an `error` event and the panel removes the turn and restores the question, as for a non-streamed failure.

**Source:** new `ResponsesStreamReader`, `StreamingResponseTransport`, `StreamingResponsesHttpClient`, `Rest/EventStream`; `WordPressResponsesHttpClient::postStream` (WordPress HTTP API plus the documented `http_api_curl` action, removed after the call); `OpenAiResponsesFileSearchTransport::respondStreaming`; `ChatService::handle` takes an optional text sink; `ChatRoute` negotiates and ends a streamed request with `exit`; `public.js` stream reader, progressive render on timers (not animation frames), caret, announcement only on completion; CSS caret (reduced-motion safe). The plugin version string is unchanged.

**Tested:** new `tests/c8-streaming.php` (chunk sizes 1 to whole, CRLF split across chunks, gate before retrieval, markers split across chunks, cap, provider failure, streamed result equal to the non-streamed result, non-2xx, no-streaming-client fallback, service outcomes for failure/unverified/fingerprint mismatch, route event order, JSON fallbacks) and stream-reader and negotiation checks in `tests/c5-public-js.mjs`. All Core PHP suites, contract, provenance, source-audit, JS tests, PHP lint and `git diff --check` pass.
