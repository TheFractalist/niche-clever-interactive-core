# Changelog

## 1.0.0-rc.1 — 12 October 2026

Local-only, mock-verified Core release candidate. It includes the C0–C4 newly authored Core foundation: single-profile administration and panel, the sole Core chat route, deterministic fixture-only retrieval/evidence controls, and privacy-bounded daily reservations.

The C5 quality increment adds the complete GPL v2 text, WordPress package metadata, direct-file guards and an external-tool-only WPCS/PHPCS ruleset. The candidate package is tested with the official Plugin Check plugin in a disposable fixture.

This is not a public release. A live File Search canary using segregated non-production resources remains required before technical acceptance. Pro is not included.
